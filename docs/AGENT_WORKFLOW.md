# Agent Workflow

## 역할

| 역할 | 수 | 산출물 |
| --- | ---: | --- |
| 레시피 조사 | 3 | 후보 비교, 계량, 조리 단계, 근거 URL |
| 콘텐츠 제작 | 3 | 세로형 이미지 시안, 카드 문구, 캡션 |
| 검토 | 1 | 근거 대조, 오탈자/안전성/시각 QA |

실습 PDF의 조사 표에 있는 `콘텐츠 조사`와 `이미지 조사`는 최종 통합 단계에서 별도 기록합니다. 두 트랙은 각각 유사 SNS 콘텐츠 최대 2개와 참고 이미지 최대 2개를 비교하고, 강조점·구도·배경·색상·출처를 최종 시안에 반영합니다. 결과는 [`research/content-image-research.md`](../research/content-image-research.md)에 남깁니다.

## 병렬화 전환

조사 에이전트 3개를 먼저 시작한다. 조사 결과가 하나씩 확정되는 즉시 해당 결과를 전달받은 콘텐츠 에이전트를 시작한다. 따라서 조사 A가 콘텐츠 A를 막지 않으며, 조사 B/C와 콘텐츠 A가 동시에 진행될 수 있다. 콘텐츠 시안 3개가 모이면 검토 에이전트를 시작한다.

## 브랜치 전략

- `codex/recipe-bootstrap`: 폴더 구조와 작업 계약
- `codex/recipe-research`: 조사 보고서
- `codex/recipe-content`: 이미지/카드뉴스 시안
- `codex/recipe-review`: 검토 보고서와 최종 통합

기능별 결과를 커밋한 뒤 최종 브랜치에 순서대로 통합한다.
